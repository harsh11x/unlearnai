Getting started

            
Remap Studios visualizes and edits neural-network weights, and runs capability unlearning. Everything runs locally — no model data leaves this machine.

            
    
              
  1. Open a model with ⌘O, drag a file onto the window, or open a folder of weights with ⌘⇧O.
    2. 
              
  2. Explore it — the Visualization tab draws the architecture, the Weight Explorer lists every tensor, the Heatmap shows value distributions.
    3. 
              
  3. Edit a tensor from the Weight Explorer, then export with ⌘E to write the changes out.
    4. 
              
  4. Unlearn a capability from the Unlearn tab, which needs a trainable (Safetensors/PyTorch) model.
    5. 
            

            
The Python environment is checked on every launch. If packages are missing the app offers to install them into its own private environment.

          

          

            
Supported formats

            
    
              
  • Safetensors — full support, including unlearning.
    • 
              
  • GGUF (quantized llama.cpp) — visualization, statistics, heatmaps and weight surgery; unlearning needs an export to Safetensors first.
    • 
              
  • PyTorch (.pt/.pth/.bin/.ckpt) — full support.
    • 
              
  • ONNX, HDF5, NumPy, TensorFlow, CoreML, pickle, IPYNB — metadata and structure where the format allows.
    • 
              
  • Folders — a HuggingFace-style directory of shards and a config.
    • 
            

            
Quantized models are edited in place without dequantizing the whole file, so a 500 MB GGUF opens in seconds rather than tens of minutes.

          

          

            
Visualizing a model

            
Press G to switch between the 2D canvas and the 3D network. In 3D:

            
    
              
  • Drag or swipe to rotate, all the way to ±89.5° pitch.
    • 
              
  • ⌥/Alt-drag or Q/E slants the view around its own axis.
    • 
              
  • Shift-drag or right-drag pans; scroll tilts; ⌘/Ctrl-scroll or pinch zooms.
    • 
              
  • L cycles the layout (Layers / Helix / Sphere), C the colour mode, Space spins, R resets.
    • 
            

          

          

            
Weights & surgery

            
Click a tensor to load its statistics and edit controls. Edits are pending until you export — the original file on disk is never modified in place.

            
    
              
  • Operations: scale, clamp, zero-fraction, add noise, add constant.
    • 
              
  • ⌘Z / ⌘⇧Z undo and redo edits.
    • 
              
  • ⌘C copies the selected names, so one edit can be pasted onto its siblings.
    • 
              
  • Right-click a weight to copy its name or path, view properties, open its heatmap, or export just that tensor.
    • 
            

          

          

            
Unlearning

            
Unlearning suppresses a capability while trying to leave the rest of the model intact. Choose a target, a method (Retain-Aware or Gradient Forgetting) and a strength, then run it with ⌘⇧R.

            
Progress streams into the Unlearn tab; cancel at any time. With Auto-save checkpoints on, a checkpoint is written when the run finishes.

            
Quantized GGUF models cannot be unlearned directly — export to Safetensors first (⌘E), then reload.

Troubleshooting

            

              
“Python backend not ready”

              
Open Settings → Backend, press Install / Repair Packages, then Restart Backend. If you use a specific interpreter, set it under Preferred interpreter.

              
Model loads but statistics are empty

              
Quantized formats are read lazily; open the Weight Explorer and use Load per-tensor statistics for exact numbers.

              
Unlearning says the model is not trainable

              
Export to Safetensors (⌘E) and reload the exported file.

              
The 3D view is slow

              
Settings → Visualization: lower the animation speed or turn off connection lines. The engine also degrades quality automatically if the frame rate drops.
